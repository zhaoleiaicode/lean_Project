### 1.1.1 项目的定义

在<span style="font-size:1.3em; font-weight:bold; color:#CC0000;">独特</span>情形下为<span style="color:#CC0000; font-weight:bold; font-size:1.2em;">创造价值</span>而进行的<span style="color:#CC0000; font-weight:bold; font-size:1.2em;">临时性</span>举措。

项目的例子：

- 开发一种新药。
- 设计新型卡车。
- 建造一座大楼。
- 合并两家公司。

### 1.1.2 项目的特点

> 项目的特点“**临时性**”

- 项目的启动旨在通过产出有形或者无形的可交付物(如产品、服务或者其他结果)来创造价值。
- 项目是临时性的，具有明确的起点和终点。
- 虽然项目具有临时性质，但是可交付物通常在项目结束后继续存在。

**当满足以下一项或者多项条件时、项目即宣告结束**：

1. 项目已经实现目标
2. 治理机构、项目发起人或者项目团队认为项目无法实现或者不会实现。、
3. 资金(资金、人力或者物力)耗尽或者不再可用。
4. 由于战略、优先级或者外部环境变化、项目不再有存在的必要。
5. 项目因为法律、法规或者合规等其他原因被终止。

> 项目的特点“**独特性**”

- 项目的独特特性是指，使某一项目区别于其他项目的特定条件和环境，即使这些项目在其他方面具有相似特性。
- 即使两个项目旨在实现相同的价值目标，由于其实施环境各异，每个项目也会有所差异。
- 应该根据每个项目的具体需要和挑战采用经过裁剪的管理方法。因此要针对每个项目的独特情景，为其量身定制相应的成功策略。

>项目的特点“**创造价值、推动变革**”

项目在追求价值的过程中、推动阻止变革。从业务角度来看，项目的宗旨是推动组织从一个状态转变为另一个状态，以实现特定目标。

项目的成功完全使组织能够迈向未来状态，并实现由关键利益相关方所定义的组织价值。

### 1.1.3 项目集和项目组合

| 项目集                                                       | 项目组合                                                     |
| :----------------------------------------------------------- | ------------------------------------------------------------ |
| 是一组相互关联且被协调管理的“项目、子项目集和项目集活动”，以便获得分别管理所无法获得的利益(关于依赖关系) | 是指为了实现战略目标而组合在一起管理的“项目、项目集、子项目组合和运营工作”，它们不一定彼此依赖或者相关。关注优先级。 |

| 维度     | 项目组合                                                     | 项目集                                                       | 项目                                                         |
| -------- | ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 定义     | 作为一组进行管理的项目集、项目和运营的集合，以最大化整体价值交付，并实现战略目标，履行强制性义务或创造收入流 | 以协调的方式管理一组相关项目和项目集活动，以获得单独管理它们所无法实现的收益 | 在独特情境下为创造价值而进行的临时性举措                     |
| 范围     | 与战略目标相一致的组织级范围                                 | 涵盖并整合其组件项目和子项目集的范围                         | 明确定义的目标，渐进明细                                     |
| 变更     | 能够适应持续监督和调整，以与战略优先级和环境变化保持一致     | 能够适应以优化项目集层面的价值交付                           | 能够适应并最大化价值交付                                     |
| 规划     | 战略规划、优先级定义，以及项目集与项目之间的资源分配         | 跟踪依赖关系并与项目集目标保持一致的高层级规划               | 预测型、适应型或混合型，具体取决于项目需求和组织情境         |
| 监督     | 监督战略变革和资源分配                                       | 监督组件项目进展和收益实现情况                               | 监督并控制输出和价值                                         |
| 成功标准 | 通过战略价值交付、整体变革管理成效，以及与组织愿景和使命的一致性来衡量 | 通过项目集整体交付收益和价值，以及实现战略目标的能力来衡量   | 通过交付的价值是否值得所付出的投入和费用来衡量，包括质量、及时性、预算合规性、可持续性和利益相关方满意度 |

### 1.1.4 运营管理与项目管理

运营管理聚焦于产品或者服务的高效、有效产出。同时，运营管理通过优化资源配置来满足客户需求并交付价值，以确保业务运营的高效性和有效性。

商业或者组织运营中的变革可成为项目的关注重点，尤其是在因为新产品或者我服务交付而产生重大需求变革时。持续性运营不属于项目的范围。
